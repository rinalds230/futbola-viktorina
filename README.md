# Futbola viktorīna

Interaktīva viktorīna par pasaules un Latvijas futbolu.

**Demo:** https://rinalds230.github.io/futbola-viktorina/

## Iespējas
- 10 nejauši jautājumi no vairāk nekā 30 jautājumu bankas, arī atbilžu secība ir nejauša
- 15 sekundes katram jautājumam
- Punkti: 100 par pareizu atbildi, līdz 50 bonusa punktiem par ātrumu un sērijas bonuss par 3 pareizām atbildēm pēc kārtas
- Rekords saglabājas pārlūkā (localStorage)
- Beigās var apskatīt savas kļūdas
- Var spēlēt ar tastatūru: 1–4 vai A–D

## Tehnoloģijas
HTML, CSS (animācijas, Grid), JavaScript (DOM, localStorage)

## Struktūra
- `questions.js` – jautājumu banka
- `app.js` – spēles loģika
- `style.css` – izskats
